📐 Problem Definition: Minimum Weighted Latency Problem (MWLP)

In emergency triage and disaster relief logistics, standard Traveling Salesperson Problem (TSP) models fail because they only minimize total travel distance, ignoring when each victim or hospital receives aid.

The Minimum Total Weighted Latency Problem (also known as the Traveling Repairman Problem with Weights or Cumulative Capacitated VRP) models a relief vehicle departing from a depot $(x_0, y_0)$ at time $t = 0$. It must visit $n$ target facilities $\{1, 2, \dots, n\}$, each assigned an urgency weight $w_i \in [1, 10]$.

$$\text{Objective:} \quad \min_{\pi \in S_n} \sum_{i=1}^n w_{\pi(i)} \cdot A(\pi(i))$$ $$\text{where } A(\pi(i)) = \sum_{k=1}^i \text{travel\_time}(\pi(k-1), \pi(k)) \quad \text{with } \pi(0) = \text{depot}$$

Why MWLP Fundamentally Differs from TSP

  • Non-Local Edge Costs: In TSP, traversing an edge $(u, v)$ adds a fixed distance $d(u, v)$ to the tour cost regardless of when it is traversed. In MWLP, traversing $(u, v)$ at step $k$ delays not only node $v$, but every subsequent unvisited node in the sequence!
  • Prefix Sensitivity: Reversing a TSP tour produces an identical total cost. In MWLP, reversing a tour drastically changes the objective function. Visiting high-urgency nodes early is heavily rewarded.
  • NP-Hardness: MWLP is strongly NP-hard even on Euclidean metrics and trees.

⚡ Dynamic Programming with Bitmask: Recurrence & Formulation

To eliminate the need to track continuous elapsed time in the state space, we use the incremental remaining penalty formulation.

When the vehicle travels from the currently visited node $u$ to a new unvisited node $v$, the transit time $\Delta t = \text{travel\_time}(u, v)$ delays node $v$ and all remaining unvisited nodes. The total weight of all unvisited nodes (including $v$) is $W_{\text{rem}}$. Hence, the immediate contribution to the total objective is:

$$\Delta \text{Cost}(u \to v) = \text{travel\_time}(u, v) \times \sum_{k \notin S} w_k$$

Let $S \subseteq \{1, \dots, n\}$ be the subset of visited nodes represented as an integer bitmask $\text{mask} \in [0, 2^n - 1]$, and let $u \in S$ be the last visited node.

$$DP[\text{mask} \cup \{v\}][v] = \min_{u \in S} \Big( DP[\text{mask}][u] + \text{travel\_time}(u, v) \times W_{\text{rem}}(\text{mask}) \Big)$$ $$\text{Base Case: } DP[1 \ll v][v] = \text{travel\_time}(\text{depot}, v) \times \sum_{i=1}^n w_i \quad \forall v \in \{1, \dots, n\}$$ $$\text{Optimal Value: } \min_{j \in \{1, \dots, n\}} DP[(2^n - 1)][j]$$

Path Reconstruction

We maintain a predecessor matrix $\text{parent}[\text{mask}][\text{last}] = u^*$. Once the full mask $2^n - 1$ is solved, the optimal path is recovered in $O(n)$ by backtracking through parent pointers.

1. Bitmask Dynamic Programming

function SolveDP(depot, locations, speed):
    n = locations.length
    numStates = 1 << n
    W_total = sum(locations[i].weight)
    
    // Initialize DP table to infinity
    dp = Array(numStates, n).fill(Infinity)
    parent = Array(numStates, n).fill(-1)

    // Base cases from depot
    for v from 0 to n-1:
        dp[1 << v][v] = travel_time(depot, locations[v]) * W_total

    // Iterate through bitmasks
    for mask from 1 to numStates - 1:
        W_rem = W_total - weight_of(mask)
        if W_rem <= 0: continue
        
        for u in mask:
            if dp[mask][u] == Infinity: continue
            for v not in mask:
                nextMask = mask | (1 << v)
                cost = dp[mask][u] + travel_time(locations[u], locations[v]) * W_rem
                if cost < dp[nextMask][v]:
                    dp[nextMask][v] = cost
                    parent[nextMask][v] = u

    return ReconstructPath(dp, parent, numStates - 1)

3. Greedy Priority Ratio Heuristic

function SolveGreedy(depot, locations):
    currentPos = depot
    unvisited = {0, 1, ..., n-1}
    order = []
    
    while unvisited is not empty:
        // Maximize urgency-to-travel-cost ratio
        best_v = argmax_{v in unvisited} (weight[v] / travel_time(currentPos, v))
        order.append(best_v)
        unvisited.remove(best_v)
        currentPos = locations[best_v]
        
    return order

Why Bitmask DP is the Superior Choice for Tactical Dispatch ($n \le 18$)

For realistic single-vehicle dispatch scenarios (where one ambulance or relief helicopter services 5 to 18 critical triage stations per sortie):

  • No Exponential Surprises: Unlike Branch and Bound, whose runtime can degrade into worst-case $O(n!)$ on symmetric or uniform distributions, Dynamic Programming runs in deterministic $\Theta(n^2 2^n)$ time.
  • Zero Approximation Risk: As proven by our "Greedy Trap" preset, greedy heuristics can suffer >20% latency penalties when lured by nearby mild casualties, leading to avoidable mortality in critical patients. DP guarantees mathematically minimal delay.

🚑 Real-World Emergency & Humanitarian Applications

The "Golden Hour" in emergency medicine refers to the first 60 minutes following severe traumatic injury or catastrophic event. Prompt intervention during this window determines survival rates.

🏥

Mass Casualty Incident (MCI) Ambulance Dispatch

In multi-vehicle pileups, building collapses, or industrial explosions, paramedics assign START (Simple Triage and Rapid Treatment) priority tags: Immediate (Red, w=10), Delayed (Yellow, w=5), and Minor (Green, w=2). GoldenHour Router ensures life-support transport reaches Red-tag victims first while minimizing total system waiting time.

🚁

Autonomous Medical Drone Delivery

Unmanned Aerial Vehicles (UAVs) carrying anti-venom, O-negative blood units, automated external defibrillators (AEDs), and epinephrine to inaccessible mountain clinics and flood-isolated rural islands.

⚡

Post-Disaster Critical Infrastructure Restoration

Following cyclones, hurricanes, or earthquakes, power grid technicians must prioritize sub-stations supplying trauma ICUs ($w=10$) and water filtration plants ($w=8$) before restoring residential circuits ($w=2$).

📦

Humanitarian Cold-Chain Supply Logistics

UN and Red Cross mobile vaccination teams transporting temperature-sensitive vaccines and emergency rations through disaster corridors where delivery degradation accelerates over time.
